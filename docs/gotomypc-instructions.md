## Next you need to customise your GoToMyPC Virtual Machine

### Change the option to not Dim the Viewer when inactive

On the top left of the window, you'll see a menu: File - View - Tools - Help

Click Tools - then Preferences

On the Viewer tab - unselect: Dim Viewer when inactive


put screenshot here

### Change the timeout value to more than 300 minutes

On the top left of the window, you'll see a menu: **File - View - Tools - Help**

Click **Tools** - then **Preferences**

On the **Security** tab - change the **Viewer Security Time-Out** to more than **300** minutes

*You will need to click the box next to the number to increase the value*
